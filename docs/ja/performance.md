# パフォーマンス

ベースラインデータ、測定方法、運用ルールは [BASELINE](../../tests/bench/BASELINE.md) を参照。再現：

```bash
uv run --with tomli --with tomlkit python tests/bench/bench.py --compare --iterations 500
```

## 概要（v0.1.0 実測）

| 指標 | 値 | 比較 |
|---|---|---|
| 解析 | 1.73× / 1.94× tomli（2 コーパス） | tomlkit 0.15.1 より 5.8–6.4× 高速 |
| 未編集 `dumps` | ほぼ O(1) | ソーススライス結合 |
| 編集後 `dumps` | O(編集規模) | ダーティノードのみ再描画 |
| 常駐メモリ | 0.67× tomlkit（予算 ≤0.7×） | tomli より高い（忠実性スタイルのコスト） |
| 準拠 | toml-test 1.0：valid 208 ファイル全通、invalid 501 ファイル全拒否 | tomlkit invalid 自己測定 208/214 |

## アーキテクチャ

1. **ソーススライス直接読み取り**：未触碰ノードの描画は `source[span]` を直接取得。未編集ドキュメントの `dumps` はほぼ O(1)
2. **編集時マテリアライズ**：trivia/スタイルメタデータはノード書き込み時にのみ構築。読み取りパスのスタイルコストはゼロ
3. **単一パス文字ディスパッチ解析**：プリコンパイル正規表現ブロックマッチング。文字ごとのループも token ごとの正規表現ストームもありません
