# コメント

コメントはその後に続くキーに帰属します。テーブルコメントはヘッダ行にあり、テーブルパスで指定します。

## エンジン

```python
doc = tomlclass.parse('port = 8000  # the port\n')

doc.comment("port")               # -> "the port"（なければ None）
doc.set_comment("port", "API port")
doc.set_comment("port", None)     # 削除（先頭の空白ごと）
```

- 置換は元の先頭空白を保持；削除はきれいに剥ぎ取る
- キーの削除では後続コメントも除去される；独立した行コメントはその場に残る

## アノテーション層：パラメータ化された注入

`Config.load` の `comments` パラメータは、スキーマの説明をコメントとして注入するかを制御します：

| モード | 動作 |
|---|---|
| `"none"`（デフォルト） | ファイルは書かれた通り完全に保持 |
| `"missing"` | コメントがなく、ファイルに存在するキーにのみ docstring の説明を注入 |
| `"all"` | ファイルに存在するすべてのスキーマフィールドのコメントを書き直す |

不変条件：デフォルト値は決して具現化されない（ファイルにないキーは注入されない）；未知のキーとそのコメントはそのまま保持される。

## マルチライン文字列

改行を含む文字列値はマルチライン文字列としてレンダリングされます：`"""` を優先し、内容が `"""` と衝突してエスケープ不要な場合は `'''` を使用します。開きQuoteは最初の行に単独で置かれ — 内容が 1 行でも本文は次の行から始まります。
