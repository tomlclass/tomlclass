# コメントシステム

コメントはそのキーに紐付きます。テーブルコメントはヘッダ行にあり、テーブルパスで指定します。

## エンジン層

```python
doc = tomlclass.parse('port = 8000  # the port\n')

doc.comment("port")               # -> "the port"（コメントなしは None）
doc.set_comment("port", "API ポート")
doc.set_comment("port", None)     # 削除（先行空白も含めて）
```

- 置換は元の先行空白をそのまま使用。削除時はコメントと先行空白をきれいに除去
- キー削除時は行末コメントも一緒に除去。独立した行コメントは元の位置に残ります

## アノテーション層：パラメータ化注入

`Config.load` の `comments` パラメータで schema 説明のコメント注入を制御します：

| モード | 動作 |
|---|---|
| `"none"`（デフォルト） | ファイルをそのまま保持 |
| `"missing"` | コメントがなく、ファイルに存在するキーにのみ docstring 説明を注入 |
| `"all"` | ファイルに存在する全 schema フィールドのコメントを schema に従って書き直し |

不変式：デフォルト値は決して永続化されません（ファイルにないキーは注入しません）。未知キーとそのコメントはそのまま保持されます。

## 複数行文字列

改行を含む文字列値は複数行文字列として描画されます：`"""` を優先し、内容が `"""` と衝突してエスケープ不要な場合は `'''` を使用します。開始の `"""` 単独行の次の行から内容が始まります。
