# 技能（Skills）

面向**本仓库开发任务**的操作手册（供代理与新贡献者使用）。内容均来自项目真实的构建与验证方式；底层事实（架构、模块清单、验证门）见 [reference](../reference/index.md)。

第一次来？先从[快速上手](quickstart.md)开始。

| 技能 | 适用场景 |
|---|---|
| [快速上手](quickstart.md) | 初次进入仓库：环境、认路、第一次安全改动 |
| [修复缺陷](fixing-defects.md) | 测试失败、往返/注释不变量被破坏、错误暴露 |
| [扩展 API](extending-api.md) | 新增或修改导出函数、类、方法、选项 |
| [测试](testing.md) | 运行、组织或新增测试 |
| [更新文档](updating-docs.md) | 修改 README、docs 页面、CHANGELOG 或本 skills/reference 文件 |
| [发布](releasing.md) | 发版、更新 changelog、发布 PyPI |

基本准则：每份手册只描述仓库的真实状态。当现实与手册冲突时，在同一变更中修手册——绝不为迎合文档而迁就仓库。
