# Комментарии

Комментарий принадлежит ключу, за которым он следует; комментарии таблицы живут в строке заголовка и адресуются путём таблицы.

## Движок

```python
doc = tomlclass.parse('port = 8000  # the port\n')

doc.comment("port")               # -> "the port" (None when absent)
doc.set_comment("port", "API port")
doc.set_comment("port", None)     # remove (with leading whitespace)
```

- При замене исходные ведущие пробелы сохраняются; при удалении они убираются чисто
- Удаление ключа убирает его завершающий комментарий; отдельные полнострочные комментарии остаются на месте

## Слой аннотаций: параметризованное внедрение

Параметр `comments` метода `Config.load` управляет тем, внедряются ли описания схемы как комментарии:

| Режим | Поведение |
|---|---|
| `"none"` (по умолчанию) | Файл остаётся ровно таким, как был написан |
| `"missing"` | Внедрить описание из docstring только для ключей без комментария, которые присутствуют в файле |
| `"all"` | Перезаписать комментарии для всех полей схемы, присутствующих в файле |

Инварианты: значения по умолчанию никогда не материализуются (ключи, которых нет в файле, не внедряются); неизвестные ключи и их комментарии сохраняются как есть.

## Многострочные строки

Строковые значения с переводами строк рендерятся как многострочные строки: предпочтительны `"""`; если содержимое конфликтует с `"""` и не требует экранирования, используются `'''`. Открывающая последовательность стоит одна на первой строке — содержимое начинается со следующей строки, даже когда оно помещается в одну строку.
