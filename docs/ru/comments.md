# Комментарии

Комментарий принадлежит ключу, за которым он следует; комментарий таблицы находится в строке её заголовка и адресуется путём таблицы.

## Движок

```python
doc = tomlclass.parse('port = 8000  # the port\n')

doc.comment("port")               # -> "the port" (None, если комментария нет)
doc.set_comment("port", "API port")
doc.set_comment("port", None)     # удалить (вместе с ведущими пробелами)
```

- Замена сохраняет исходные ведущие пробелы; удаление убирает их чисто
- При удалении ключа его строчный комментарий убирается вместе с ним; отдельные строковые комментарии остаются на месте

## Слой аннотаций: параметризованная вставка

Параметр `comments` метода `Config.load` управляет вставкой описаний из schema как комментариев:

| Режим | Поведение |
|---|---|
| `"none"` (по умолчанию) | Файл остаётся как написан |
| `"missing"` | Описание из docstring вставляется только для ключей без комментария, присутствующих в файле |
| `"all"` | Комментарии всех полей schema в файле перезаписываются по schema |

Инварианты: значения по умолчанию не материализуются (ключи не из файла не вставляются); неизвестные ключи и их комментарии сохраняются как есть.

## Многострочные строки

Строковые значения с переводами строк рендерятся как многострочные строки: предпочтительны тройные двойные кавычки `"""`; если содержимое конфликтует с `"""` и не требует экранирования, используются тройные одинарные `'''`. Открывающая кавычка стоит на отдельной строке — содержимое начинается со следующей.
