# Производительность

Базовые данные, методика измерений и правила сопровождения: [BASELINE](../../tests/bench/BASELINE.md). Воспроизведение:

```bash
uv run --with tomli --with tomlkit python tests/bench/bench.py --compare --iterations 500
```

## Кратко (v0.1.0, измерено)

| Показатель | Значение | Сравнение |
|---|---|---|
| Разбор | 1.73× / 1.94× tomli (два корпуса) | в 5,8–6,4 раза быстрее tomlkit 0.15.1 |
| Неизменённый `dumps` | ~O(1) | склейка срезов источника |
| `dumps` после правки | O(объём правок) | перерисовываются только «грязные» узлы |
| Память | 0.67× tomlkit (бюджет ≤0.7×) | больше tomli (стоимость сохранения стиля) |
| Соответствие | toml-test 1.0: все 208 valid пройдены, все 501 invalid отклонены | у tomlkit self-test invalid 208/214 |

## Архитектура

1. **Чтение из срезов источника**: нетронутые узлы рендерятся напрямую из `source[span]`; `dumps` неизменённого документа почти O(1)
2. **Материализация при правке**: метаданные trivia/стиля строятся только при записи узла — путь чтения не платит за стиль
3. **Однопроходный посимвольный разбор**: предкомпилированные блоковые регулярные выражения, без посимвольных циклов и регулярок на каждый токен
